# Goal: Issue Triage & Root Cause Assessment

Analyze open GitHub issues, evaluate reproducibility, assess root causes, and propose precise target files and test verification scenarios.

## Focus Areas
1. **Issue Analysis**: Examine issue descriptions, reproduce steps locally where practical, and map to target source files.
2. **Deduplication**: Prevent duplicate issue creation by cross-referencing open issues and open PRs.
3. **Actionable Task Formulation**: Formulate issues with precise target file paths, expected behavior, and concrete verification steps.

## Rules
- Do not generate vague or speculative issues.
